Issue 4 — Monitor de Brechas: UI confusa + barras en 0%

Dos sub-problemas: (1) las barras de similitud muestran 0% y (2) no se entiende qué significa cada parte del resultado.

Sub-problema 1: barras de similitud

El score coseno está entre 0.0 y 1.0 pero los valores reales del corpus son muy bajos (ej: 0.03). Se muestran como 3% — visualmente vacíos. Opciones:

A

Normalizar al máximo del resultado

La barra más alta del lote = 100%. Las demás se escalan relativamente. El valor numérico muestra el score real.

Dataset A (0.42)
0.42
Dataset B (0.31)
0.31
Dataset C (0.18)
0.18

Visualmente informativo. El usuario ve relevancia relativa. Score real al costado para quien quiera el valor exacto.

B

Reemplazar barra por ranking ordinal

Sin barra de porcentaje. Solo un badge con el orden (#1, #2, #3…) y la etiqueta de calidad.

#1 Dataset A Completa
#2 Dataset B Parcial

Evita el problema del 0% completamente. Más limpio pero pierde info de qué tan relevante es cada resultado.

Sub-problema 2: explicaciones en pantalla

El ScorePanel muestra un número grande, 3 pills de agenda y un termómetro, pero sin contexto. ¿Qué nivel de explicación querés?

X

Labels descriptivos + tooltip en score

El score grande lleva una etiqueta "Score de brecha (0=cubierto, 100=crítico)". Las agendas tienen tooltip ⓘ. El termómetro tiene una escala visible.

Mínimo invasivo. No cambia el layout, solo agrega contexto.

Y

Panel de interpretación debajo del score

Una sección colapsable "¿Qué significa este resultado?" con texto generado dinámicamente según la categoría (crítica / parcial / cubierta).

Más explicativo para usuarias nuevas. Puede sentirse verboso para usuarias frecuentes.

Mi recomendación: A + X — barras normalizadas al máximo + labels descriptivos con tooltips.
